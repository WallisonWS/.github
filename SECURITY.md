# 🛡️ Security Policy

## Reporting a Vulnerability

Security is a core priority across all **@WallisonWS** open-source projects (`headroom-shield`, `aegis-llm-guard`, `devsecops-toolkit`, `mcp-sentinel-firewall`, `sre-osv-sentinel`, `ai-code-sec-scanner`, and related tools).

If you discover a security vulnerability:
1. **Do not** open a public issue with exploit details.
2. Report it responsibly via **GitHub Security Advisories** (Private Vulnerability Reporting) or email **wallisonoficial85@gmail.com**.
3. Include steps to reproduce, affected version/commit, and potential impact.

We aim to acknowledge reports within **48 hours** and release fixes promptly with full credit to reporters who wish to be acknowledged.
