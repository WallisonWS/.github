# 🤝 Contributing to @WallisonWS Open-Source Projects

Thank you for considering contributing! Every issue, bug fix, translation (`EN` / `PT-BR` / `ES`), new rule, or documentation improvement helps thousands of developers and analysts worldwide.

## 🚀 Quick Ways to Contribute
1. **Pick a [`good first issue`](https://github.com/search?q=user%3AWallisonWS+label%3A%22good+first+issue%22+state%3Aopen&type=issues)** — every flagship repository includes beginner-friendly roadmap issues.
2. **Add New Detection / Transpiler Rules:** Firewall vendors, CWE SAST rules, OWASP LLM heuristics, or new language translations.
3. **Improve Docs & Tests:** Add real-world benchmarks, edge-case unit tests, or framework integration examples.

## 🛠️ Pull Request Workflow
1. **Fork** the target repository and create a branch (`git checkout -b feat/your-improvement`).
2. Keep dependencies **zero** (Python stdlib / pure WebCrypto JS) whenever possible.
3. Run the unit tests (`python3 -m unittest discover -s tests -v`).
4. Open a clear **Pull Request** explaining what changed and why.
